# BLOXX
BLOXX is a minimal, 3d-printable modular storage system with Croc-like customization while still being useful. The minimal amount of features was due to time constraints, but it allows for people to see the bare bones of the system and add their own modules. It starts with a 1x1 and 1x2 module to boot, along with their casings and a rail system to mount them to walls or tables.
